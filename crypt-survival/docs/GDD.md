# Crypt Survival — дизайн-документ

Survivor-like по образцу Vampire Survivors на ассетах «Пиксельного склепа» (`MikhailMaltsev/pixel-crypt`).
Отдельная игра: свой репозиторий, свои сохранения и мета. Код и арт переносятся из pixel-crypt.

Все числа — стартовые значения для балансировки.

## 1. Каркас

| Параметр | Значение |
| --- | --- |
| Экран | `<canvas>` 320×192, целый множитель, как в pixel-crypt |
| Забег | 15:00, затем босс стадии |
| Стадии | 10 = 10 биомов pixel-crypt, открываются по очереди (победа над боссом) |
| Атака | Автоматическая: каждое оружие стреляет само по своей перезарядке |
| E | Ручная способность героя на перезарядке (как в pixel-crypt) |
| Поле | Бесконечное, генерируется чанками |
| Слоты | 4 оружия + 4 пассивки |
| Уровни предметов | Оружие 1–8, пассивка 1–5 |

### Таймлайн стадии

| Время | Событие |
| --- | --- |
| 0:00–15:00 | Новый набор волн каждую минуту из ростера биома |
| 5:00, 10:00 | Элитный гигант (враг биома ×2 размер, ×20 HP) — роняет сундук |
| 3:00, 8:00, 13:00 | Рой: кольцо летучих мышей / поток крыс поперёк экрана |
| 15:00 | Босс биома; спавн обычных врагов останавливается |
| Босс убит | Сундук с эволюцией + золотой портал → стадия пройдена |
| 20:00 | Если игрок остался — Жнец (неуязвимый, убивает за касание) |

## 2. Поле

- **Чанк** 16×16 тайлов (256×256 px, чуть больше экрана). Генерация от `seed + (cx, cy)` (`mulberry`).
  В памяти 5×5 чанков вокруг игрока, дальние выгружаются; набор разбитого декора чанка
  живёт, пока чанк в памяти.
- **Пол** — только картинка: плитка биома + наземный декор (плиты, решётки, кости, паутина, лужи).
- **Препятствия** — редкие: обломки стен, колонны, 0–2 кластера на чанк. Враги скользят вдоль
  (`moveEnt`), летуны пролетают.
- **Ловушки биома** (со 3-й стадии) — редкие пятна: лава, шипы, пила на рельсе. Ранят и врагов.
- **Ориентиры** раз в 4–6 чанков: часовня с сундуком под охраной элитки, зал саркофагов, алтарь.
  На HUD стрелка к ближайшему сундуку / боссу.

## 3. Враги и спавн

- **Ростер** — враги своего биома (`EN` из `level.js` + модули биомов). Стадия 1, склеп:
  слизень, летучая мышь, скелет, призрак, паук, культист, кость, зомби, ползун.
- **ИИ толпы** — простое преследование + мягкое расталкивание соседей. Особое поведение
  (прыжки паука, телепорт культиста, щит стража) — только у элиток и боссов.
- **Спавн** — кольцо сразу за краем экрана. Раз в 1 с приходят `0.5 + m/4` новых врагов при любой
  толпе, и толпа добирается до минимума `N(m) = min(10 + 8·m, 120)`. Враг дальше 1.3 радиуса
  спавна переносится вперёд по ходу движения.
- **Рост силы**: `hp = base · (1 + 0.2·m) · (1 + 0.35·(stage − 1))`, где `m` — минута.
- **Урон игроку** — в четвертях сердца, как в pixel-crypt (`HPH = 4`). Касание — 1 четверть,
  неуязвимость после удара 0.6 с.
- **Элитка** — перекраска (`tintOf`) + ×2 размер, ×20 HP, особое поведение, роняет сундук.

## 4. Опыт

### Осколки душ

| Осколок | Опыт | Откуда |
| --- | --- | --- |
| Голубой | 1 | Обычные враги с `xp ≤ 4` |
| Зелёный | 5 | Враги с `xp 5–24`; слияние |
| Красный | 25 | Элитки, боссы; слияние |

- Опыт врага: `xp = ceil(EN.score / 10)` — слизень 1, скелет 3, культист 4, страж 6, мимик 8.
- Больше 150 осколков на поле → дальние сливаются в один крупный.
- Радиус подбора 32 px (пассивка «Амулет душ» +25 % за уровень). Подобранный осколок летит к игроку.

### Кривая

Опыт на переход L → L+1: `5` для L = 1, далее `+10` за уровень до 20, `+13` до 40, `+16` дальше.

Темп проверен ботом в прототипе (кайт + сбор осколков): 10–13 уровень к 4–5 минуте, 47–48 к 15:00.

| Уровень | Опыт всего | Цель по времени |
| --- | --- | --- |
| 10 | ~405 | 3:00 |
| 20 | ~1 805 | 7:00 |
| 30 | ~4 400 | 11:00 |
| 40 | ~8 235 | 14:00 |

### Выбор при уровне

- 3 карточки (4 при удаче ≥ 30 %). Пул: новые предметы, пока есть свободные слоты, и уровни
  имеющихся. Имеющиеся выпадают в 2 раза чаще.
- Уникальный перк героя на 10/20/30 уровне гарантированно в выборе (механика `fresh` из pixel-crypt).
- Всё прокачано → «Мешок золота» (+25 золота) или «Эликсир» (полное лечение).
- Мета-покупки: повтор, пропуск, запрет карты.

## 8. Герои

- Статы, цены и E — из `HEROES` pixel-crypt.
- Врождённая пассивка + уникальный перк на 10/20/30 уровне, который усиливает E
  (модель — ПЕКЛО и ЖАТВА из pixel-crypt).
- Оборотень: ×2 урона на последнем сердце. Тень: ×3 урона первому удару из невидимости. Вампир:
  стартует с Жаждой крови 1.

## 9. Разрушаемый декор и лут

Механика — враг-реквизит (`prop` + `onBreak`, как ледяные блоки). Любое оружие бьёт декор.
Плотность: 1–3 предмета на чанк.

| Биом | Мелкие (1 удар) | Крупные (3–5 ударов) |
| --- | --- | --- |
| Склеп | свечи, кучи костей | саркофаг, гроб, алтарь, мёртвый искатель |
| Чума | склянки, бутыли | телега с телами, гроб |
| Собор | канделябры | скамьи, колокол |
| Пирамида | урны, маски | саркофаг фараона |
| Пепел / литейня | шлак, формы | доспех на стойке |
| Лёд | сосульки | ледяной блок |
| Гнездо | яйца | кокон |
| Пустота | рунные мины | пилон |

### Таблицы лута

| Источник | Лут |
| --- | --- |
| Мелкий декор | 55 % монеты, 25 % сердце, 10 % магнит, 5 % бомба, 5 % пусто |
| Крупный декор | гарантированно одно: сердце / мешок золота; +15 % магнит, +10 % бомба |
| Обычный враг | осколок; 3 % монета |
| Элитка | красный осколок + сундук |
| Босс | красные осколки + сундук с эволюцией |

**Редкое**: бомба-череп (зачищает экран), ледяная звезда (заморозка всех на 5 с),
кровавый кубок (вампиризм 15 с), сундук с улучшением.

**Сундук**: 1 улучшение (80 %), 3 (15 %), 5 (5 %); эволюция, если готова.

**Сюрпризы**: из гроба может встать зомби, из саркофага — мумия-элитка, из трупа — ползун,
из кокона — паучата, вместо сундука — мимик (~10 % крупного декора).

Свечи и канделябры — источники света (`clights`); разбил — темнее.

## 10. Мета

- **Золото** — кошелёк между забегами. Источники: монеты, мешки, бонус за стадию.
- **Герои** — покупка за золото.
- **Тренировка** (по образцу `train`, `TRAIN_STEP · 2^n`): сила, сердце, броня, скорость, площадь,
  перезарядка, магнит, удача, рост, жадность, повтор, пропуск, запрет.
- **Открытия оружия** — достижения: «убей N», «продержись N минут героем X», «разбей N гробов».
- **Стадии** — по очереди, за победу над боссом.

## 11. Техника

- Чистый JS без сборки, модули через `<script>`, как в pixel-crypt.
- **Переносим как есть**: `core.js`, `sprites.js` и спрайты биомов, `audio.js`, `input.js`,
  `gamepad.js`, `i18n.js` + `lang/`, `pg.js`, `prefs.js`, `fullscreen.js`, `vibe.js`, шрифты.
- **Адаптируем**: `EN` (рост по минутам), атаки героев → оружие, `UPGRADES` → пассивки,
  `rollChoices`.
- **Пишем заново**: мир чанками и камера, спавнер, ИИ толпы, пространственная сетка (ячейка 32 px),
  осколки и магнит, HUD слотов, свои сохранения (`cryptsurvival_save`).
- **Производительность**: ≤ 120 активных врагов, пулы объектов, лимит частиц.
