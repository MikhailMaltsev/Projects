# Crypt Survival

Survivor-like по образцу Vampire Survivors на ассетах «Пиксельного склепа» (`MikhailMaltsev/pixel-crypt`):
бесконечное поле склепа, толпы нежити, автоатака, осколки душ и выбор улучшений за уровни.
Чистый JavaScript без сборки, `<canvas>` 320×192 с целым множителем.

Дизайн — [docs/GDD.md](docs/GDD.md). Сейчас — прототип M1.

## Играть

```sh
python -m http.server 8137 --bind 127.0.0.1
```

и открыть http://127.0.0.1:8137/. WASD или стрелки — ходьба, атака сама; Esc — пауза.
На телефоне — палец на поле работает как джойстик.

## Модули

| Файл | Что там |
| --- | --- |
| `js/core.js` | Константы, канвас, утилиты |
| `js/sprites.js`, `js/audio.js` | Спрайты и звук из pixel-crypt без изменений |
| `js/state.js` | Состояние забега, герои, сохранение |
| `js/world.js` | Бесконечное поле чанками, декор, разрушаемые предметы и их лут |
| `js/enemies.js` | Враги, волны по минутам, толпа, урон |
| `js/weapons.js` | Оружие, пассивки, снаряды |
| `js/xp.js` | Осколки душ, предметы, уровни, выбор улучшений |
| `js/player.js` | Герой, частицы, всплывающий текст |
| `js/screens.js` | Текст, кадр, HUD, экраны |
| `js/input.js` | Клавиатура и сенсорный джойстик |
| `js/main.js` | Забег и игровой цикл |
